# Advanced
A few setup tasks for less common situations: keeping local backups, exposing Wings from behind a home network, and running it under Podman instead of Docker.

::::tabs
=== Backup Configurations
Configure where and how Wings stores local server backups. See [Backup Configurations](./backup-configurations.md).

=== Exposing Wings in a Homelab
Make a Wings node reachable from the internet when it's running on a home network. See [Exposing Wings in a Homelab](./exposing-wings-in-a-homelab.md).

=== The Private Network
Connect servers across nodes so they reach each other without going over the public internet. See [The Private Network](./private-network.md).

=== Running Wings with Podman
Run Wings using Podman instead of Docker. See [Running Wings with Podman](./running-wings-with-podman.md).
::::
